# Expense Tracker

Expense Tracker is a mobile application built with Ionic React and Node.js that helps users manage their personal finances.

## Features

- **Transaction Management:** View, add, edit, and delete income and expenses.
- **User Authentication:** Register and log in to access personal financial data.
- **Offline Support:** Access and manage transactions without an internet connection.
- **Online Synchronization:** Synchronize transactions with a remote server.
- **Real-Time Updates:** Receive transaction updates through WebSockets.
- **Financial Statistics:** View spending summaries, balances, and charts.
- **External Services:** Use Google Maps to associate transactions with locations.
- **Local Services:** Use the device camera to capture receipts.
- **Animations:** Animated transitions and interactive charts.

## Technologies

- **Frontend:** Ionic React, TypeScript
- **Backend:** Node.js, Express
- **Database:** SQLite
- **Communication:** REST API, WebSockets
